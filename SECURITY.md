# Politique de sécurité

Ne signalez pas une vulnérabilité dans une issue publique. Contactez le porteur du projet en
privé, en décrivant le problème, les étapes de reproduction et l’impact.

Règles du dépôt :

- aucun secret dans le code ni dans l’historique Git (`.env` est ignoré) ;
- aucune donnée réelle d’élève, de parent ou d’enseignant, y compris dans les tests ;
- les valeurs de `.env.example` et de `docker-compose.yml` sont réservées au développement local.

Le modèle de menace est tenu à jour dans [docs/securite/modele-de-menace.md](docs/securite/modele-de-menace.md).
